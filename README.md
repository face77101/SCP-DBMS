# 🔒 SCP 資料庫管理系統 (SCP-DBMS)

> **[ SECURITY NOTICE ]** > 本系統包含最高機密異常對象資料。未授權人員企圖存取將觸發「迷因殺害媒介」。  
>⚠️ **專案權限等級需求：O5議會成員限定(當然，掌管生殺大權的助教和教授大人擁有最高權限)**

本專案為師大資工系資料庫理論第七組的期末專題，旨在實作一個具備**動態安全性限制控制**與**收容失效連鎖應變**的權限分級資訊管理系統。


---

## 🛠️ 系統核心架構

本系統嚴格遵循「關注點分離」原則，將初始化情報、資料庫骨架、後端防線與前端視覺完全解耦：

* **`database/` (儲存層)**：包含核心 DDL 骨架（`schema.sql`）與基金會初始化情報（`seed_data/`）。
* **`backend/` (邏輯層)**：處理帳密安全比對（Bcrypt 雜湊）、動態權限過濾（SQL Query）與 API 串接。
* **`frontend/` (展示層)**：SCP 機密暗黑風格控制面板，實作權限不足時的 HTML/CSS 馬賽克與黑條遮蔽。

---

## 🔐 安全防護機制 (Security Standard)

為了符合基金會最高資安規格，系統實作以下防禦：
1.  **物理防護（分頁隔離）**：`index.html` 僅包含登入框。禁止將機密畫面與登入寫在同檔，徹底防範透過瀏覽器檢視原始碼造成的情報洩漏。
2.  **落地加密（密碼雜湊）**：資料庫絕對不儲存明文密碼。所有人員密碼在初始化匯入時，一律通過 `Bcrypt` 演算法進行**單向不可逆雜湊與隨機Salting**，並引入工作因子抗衡暴力破解。
3.  **憑證防護（環境變數）**：雲端 MySQL 的連線字串存於本地端 `config.env`，並受 `.gitignore` 管制，絕不上傳 GitHub，防範網路爬蟲竊取資料庫主機控制權。

### 🚀 團隊快速啟動指南 (Quick Start)

請各位 O5 議會的大人物們（我親愛的爆肝組員們）依據以下步驟，透過 Docker **一鍵配置**本地端的開發環境，再也不用痛苦地在自己電腦裝環境跟套件了：

#### 步驟 1：建立本地端環境變數
在專案最外層（根目錄），你會看到 `config.env.example` 範本檔。請複製該檔案、重新命名為 **`config.env`**，並填入私下發放的IP、密碼：

```env
SERVERNAME=學校遠端伺服器IP
USERNAME=team07
PASSWORD=moodle之前發的小組密碼
DBNAME=team07
EXTERNAL_API_KEY=群組內發放密鑰
```
 另外，我已經將`config.env`列入 `.gitignore` 阻擋名單了，請放心。 

#### 步驟 2：啟動 Docker 虛擬貨櫃集群
確保你的電腦已經下載並啟動了 **Docker Desktop**。

打開電腦的終端機（Terminal / PowerShell）並切換到本專案的根目錄下，直接輸入以下命令：

```bash
docker-compose up --build
```
💡首次配置完環境後，只要環境或所需套件沒有更新就**不用再重新build！** 日常開發輸入以下命令即可：
```bash
docker-compose up
```
#### 步驟 3：啟動成功的訊號
按下 Enter 後，Docker 會自動去商店抓取 Linux 版的 Nginx 與 Python 3.10 環境，並自動裝妥 `requirements.txt` 的所有套件。當字停下來後，請打開瀏覽器驗證：

* 📥 **前端大廳門衛**：瀏覽網址 `http://localhost` ──> 看到網頁畫面（代表 Nginx 成功站崗）。

  *目前只有施工中的訊息，還有 testing testing 123~*
* 🧪 **後端邏輯核心**：瀏覽網址 `http://127.0.0.1:5000` ──> 看到 Flask 成功回應。

  *確保有"恭喜你測試成功！"等字樣*

至此，環境建置完全結束！只要你修改 `backend/` 或 `frontend/` 裡的任何程式碼並儲存，Docker 內部都會透過虛擬傳送門（Volume）即時同步，網頁重新整理即可看到結果。
