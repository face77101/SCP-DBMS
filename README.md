# 🔒 SCP 資料庫管理系統 (SCP-DBMS)

> **[ SECURITY NOTICE ]** > 本系統包含最高機密異常對象資料。未授權人員企圖存取將觸發「迷因殺害媒介」。  
>⚠️ **專案權限等級需求：Level 5 (Top Secret)**

本專案為師大資工系資料庫理論期末專題，旨在實作一個具備**動態安全性限制控制**與**收容失效連鎖應變**的權限分級資訊管理系統。

---

## 🛠️ 系統核心架構

本系統嚴格遵循「關注點分離」原則，將初始化情報、資料庫骨架、後端防線與前端視覺完全解耦：

* **`database/` (儲存層)**：包含核心 DDL 骨架（`schema.sql`）與基金會初始化情報（`seed_data/`）。
* **`backend/` (邏輯層)**：處理帳密安全比對（Bcrypt 雜湊）、動態權限過濾（SQL Query）與 API 串接。
* **`frontend/` (展示層)**：SCP 機密暗黑風格控制面板，實作權限不足時的 HTML/CSS 馬賽克與黑條遮蔽。

---

## 🔐 安全防護機制 (Security Standard)

為了符合基金會最高資安規格，系統實作以下防禦：
1.  **物理防護（分頁隔離）**：`index.html` 僅包含登入框。禁止將機密畫面與登入寫在同檔，徹底防範透過瀏覽器檢視原始碼（F12）造成的情報洩漏。
2.  **落地加密（密碼雜湊）**：資料庫絕對不儲存明文密碼。所有人員密碼在初始化匯入時，一律通過 `Bcrypt` 演算法進行**單向不可逆雜湊與隨機加鹽（Salting）**，並引入工作因子抗衡暴力破解。
3.  **憑證防護（環境變數）**：雲端 MySQL 的連線字串存於本地端 `config.env`，並受 `.gitignore` 管制，絕不上傳 GitHub，防範網路爬蟲竊取資料庫主機控制權。
